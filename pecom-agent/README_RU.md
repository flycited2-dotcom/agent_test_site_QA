# Помощник по ТК ПЭК (Telegram-бот + API личного кабинета)

Бот работает напрямую с **API личного кабинета ПЭК** (`https://kabinet.pecom.ru/api/v1/`) и умеет:

| Функция | Метод API ПЭК |
|---|---|
| 🧮 Расчёт стоимости и сроков (LTL-авто, авиа, EasyWay), забор/доставка, страховка, защитная упаковка | `branches/findzonebyaddress` → `calculator/calculateprice` |
| 📦 Статус груза по коду, детализация, ключевые даты | `cargos/basicstatus`, `cargos/currentstatus` |
| 🕓 Полная история статусов | `cargos/statusfullhistory` |
| 🔔 Подписка: бот сам пишет при смене статуса (проверка раз в 30 мин) | `cargos/basicstatus` + `cargos/currentstatus` |
| 🏢 Ближайшие отделения/ПВЗ для сдачи или получения груза | `branches/nearestdepartments` |
| ✅ Проверка, обслуживает ли ПЭК адрес | `branches/findzonebyaddress` |
| 📋 Мои грузы из личного кабинета за N дней | `cargos/listallorderbylogin` |
| 👤 Данные личного кабинета | `auth/profiledata` |
| 💬 ИИ-режим (необязательно): вопросы обычным текстом, Claude сам вызывает нужные методы ПЭК | — |

Цифры (стоимость, сроки, статусы) всегда берутся из ответа API ПЭК. ИИ только понимает вопрос и вызывает инструменты.

## Что нужно

1. **Логин личного кабинета ПЭК.** API использует Basic-аутентификацию: логин ЛК + ключ API.
   Одного ключа недостаточно: без логина ПЭК отвечает «Неверный логин или ключ API».
2. **Ключ API**: ЛК ПЭК → «Регистрационные данные» → «Ключи API».
3. **Токен Telegram-бота**: напишите @BotFather → `/newbot` → скопируйте токен.
4. (Необязательно) **ANTHROPIC_API_KEY** для ИИ-режима: https://console.anthropic.com/

## Настройка

```bash
cd pecom-agent
cp .env.example .env
```

Заполните в `.env`: `PEC_LOGIN`, `PEC_API_KEY`, `TELEGRAM_BOT_TOKEN`.
`.env` в git не попадает.

## Проверка подключения к ПЭК

```bash
npm install
```

```bash
npm run check
```

Должны вывестись данные профиля ЛК и список тарифов, в конце строка `OK: API ПЭК доступен`.

Ручные запросы:

```bash
npm run cli -- track 780339690775
```

```bash
npm run cli -- calc "Симферополь; Москва; 50; 60x40x30; 2; 15000"
```

```bash
npm run cli -- offices "Симферополь" send
```

## Запуск бота

```bash
npm run bot
```

1. Напишите боту в Telegram — он ответит «Доступ закрыт. Ваш chat id: …».
2. Впишите этот id в `TELEGRAM_ALLOWED_CHAT_IDS` в `.env` (несколько id — через запятую) и перезапустите бота.
   Пока список пустой, бот никому не показывает данные вашего ЛК.

### На сервере через Docker

```bash
docker compose up -d --build
```

```bash
docker compose logs -f pecom-agent
```

Подписки и позиция чтения Telegram хранятся в `storage/` и переживают перезапуск.

## Как пользоваться

Кнопки меню: «Рассчитать доставку», «Отследить груз», «Отделения ПЭК», «Мои грузы», «Подписки», «Помощь».

Команды:

```text
/calc                                         пошаговый расчёт
/calc Москва; Симферополь; 50; 60x40x30; 2; 15000
      откуда; куда; вес кг; габариты места (см) или «0.5 м3 макс 1.2»; мест; объявленная стоимость
/track 780339690775                           статус (можно несколько кодов)
/history 780339690775                         история статусов
/watch 780339690775   /unwatch 780339690775   подписка на изменения
/watches                                      список подписок
/office Симферополь, ул. Киевская 1           отделения для сдачи груза
/check адрес                                  обслуживает ли ПЭК адрес
/my 30                                        мои грузы за 30 дней
/profile                                      данные ЛК
/reset  /cancel  /id  /help
```

Если просто прислать код груза, бот покажет статус. С `ANTHROPIC_API_KEY` можно писать как человеку:
«сколько будет стоить 3 коробки по 12 кг 50×40×40 из Симферополя в Краснодар с доставкой до двери?»

## Особенности расчёта

- Склады отправления/получения бот берёт из `branches/findzonebyaddress` (`mainWarehouseId`, основное отделение филиала).
- Забор и доставка считаются по адресу, поэтому для них в «откуда/куда» указывайте полный адрес: город, улица, дом.
- Плановая дата сдачи груза — ближайший будний день, 10:00.
- Тариф 5 (Express Авто) метод расчёта ПЭК не поддерживает. Тарифы 12 и 7 работают только по договору.
- Стоимость ориентировочная, итог — по факту приёмки груза.

## Структура

```text
src/pec-api.ts   клиент API ПЭК (Basic-auth, JSON, gzip, разбор ошибок)
src/services.ts  расчёт, трекинг, отделения, форматирование ответов
src/agent.ts     ИИ-агент на Claude с инструментами ПЭК
src/bot.ts       Telegram-бот: меню, пошаговый расчёт, подписки, доступ по chat id
src/cli.ts       проверка подключения и ручные запросы
```
